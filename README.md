# EMBER — Coffee & Slow Mornings

A fictional independent coffee bar concept. Built with HTML, CSS, JavaScript and locally vendored Three.js 0.170.0. No build step or API keys required.

## Local preview

Run `npm run dev` in this directory, then open http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax checks. Deploy the `dist` directory to any static host.

## Experience

- Real WebGL ceramic cup, branded curved label, latte art, saucer and floating beans.
- Scroll-linked rotation, lateral movement and cup/saucer separation across three scenes.
- Pointer-responsive perspective, ambient animation toggle and reduced-motion handling.
- Responsive editorial layout, locally served fonts, optimized WebP images and photographic WebGL fallback.
- Accessible native menu dialog with coffee, slow-sip and bakery categories; keyboard dismissal and focus management.
- Fictional concept clearly identified. No real address, bookings, transactions or mailing-list collection.

## Assets and verification

Both photographs were created using the built-in image-generation tool. Original PNGs are in `art-originals`; the website uses `dist/assets/cafe.webp` and `dist/assets/coffees.webp`. Prompts are recorded in `ART-DIRECTION.md`. The 3D model and its textures are generated in `dist/app.js`.

Browser checks covered desktop (1440px) and mobile (390px), successful WebGL rendering, horizontal overflow, scroll navigation, menu filtering, modal close controls and visit information. This is browser emulation, not a physical-device performance benchmark.

Hosting begins private. The demonstration must be shared or made public before an external client can access it.
